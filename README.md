# Professional_Calculator
Professional Scientific Calculator using Python and Tkinter.

🚀 **Project Showcase | Build Calculator – Professional Scientific Calculator**

I'm excited to showcase my **Build Calculator**, a desktop-based scientific calculator developed using **Python and Tkinter**.

This application brings multiple calculation tools together in one user-friendly interface.

### 🔹 Key Features
- Basic Arithmetic Operations
- Scientific Functions – Sin, Cos, Tan, Log, Square Root and π
- Calculation History
- GST Calculator
- Loan EMI Calculator
- Age Calculator
- BMI Calculator
- Unit Converter

### 🛠️ Technologies Used
Python | Tkinter | Math | AST | Operator | PyInstaller

### 💻 Application Highlights
- Interactive Graphical User Interface (GUI)
- Windows EXE Application
- Multiple calculation tools in one application
